AMSA
====

AMSA is a high-performance Clifford algebra library for robotics, engineering, and scientific computation.

It is built on a matrix-free core: blades are bit-pattern identifiers, layouts describe coefficient ordering and support, and execution is planned from sparse support patterns rather than dense basis tables.
